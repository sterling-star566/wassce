# WASSCE Tracker
Developed by John-Sterling.

Track scores with WASSCE grades (A1 to F9), flag difficult topics and find videos, build your own timetable and get reminders.

Build: push to GitHub, open Actions, download the `wassce-tracker-apk` artifact and install `app-debug.apk`.
App code is in `www/index.html`; launcher icons are in `resources/res`.
